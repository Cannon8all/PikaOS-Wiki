# Translate on Weblate

## How does this help us?

Translating PikaOS on Weblate is a fantastic way to contribute and make the distribution accessible to a wider global audience. By providing translations for the user interface and documentation, you directly help speakers of other languages use and enjoy PikaOS without a language barrier. This not only grows the PikaOS community but also strengthens it by fostering inclusivity and making the operating system truly welcoming for everyone, everywhere. It's a valuable contribution that directly impacts the user experience for many.

## Notes

- Make sure to maintain spaces, brackets, newlines, symbols, format, brackets and structure of the English Translation

### Examples

#### Example 1 (bracket handling)

English Source

> ) Must at least be 512MBs!

Wrong Translation

> Размерът на EFI дялът е малък

Correct Translation

> ) Размерът на EFI дялът е малък!

#### Example 2 (space handling)

English Source

> ` PikaOS Welcome`

Wrong Translation

> `PikaOS инсталатор`

Correct Translation

> ` PikaOS инсталатор`

#### Example 3 (format handling)

English Source

> `Partition Size: {SIZE}`

Wrong Translation

> `Taille De La Partition: {TAILLE}`

Correct Translation

> `Taille De La Partition: {SIZE}`
