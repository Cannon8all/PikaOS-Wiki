# Booting the Installer

Once the system begins booting from the USB, wait for the bird logo to appear.

Press Enter to load the installer environment.

![pikaboot.png](/pikaboot.jpg)

After a short loading period, the installer will appear.

![installer.png](/installer.jpg)

Select Install Distro to System and follow the guided steps until the process completes.

When prompted, reboot your system.

## Important Information for MSI Systems

If you are installing PikaOS on an MSI motherboard or laptop, open Advanced Options in the boot menu and choose

BOOTX64 Mode (MSI Compatibility Mode).

![partitioning7.png](/partitioning-images/partitioning7.png)

When installation finishes, reboot as instructed.

![installed.png](/installed.jpg)
