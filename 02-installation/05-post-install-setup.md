# Post-install setup

## First Boot

After rebooting, press Enter at the bird logo to start your new system.

Once the desktop loads, the first boot wizard will appear automatically.

![firstboot.png](/firstboot.jpg)

Select Lets Start and complete the setup steps.

![firstbootcomplete.png](/firstbootcomplete.jpg)

Reboot when the wizard instructs you to.

## Welcome to PikaOS

Your installation is now complete.

After the final reboot, you will be greeted by the Pika Hub application, which will guide you through the next steps of using your new system.

![welcome.png](/welcome.jpg)
